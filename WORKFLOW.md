# OLX Lead-Gen: координация параллельных агентов

Этот репозиторий — общая память двух и более агентов ZCode, которые ищут лидов на OLX
(мастера без своих сайтов), делают им демо-сайты и рассылают предложения в чат OLX.

## Главное правило

ОДИН ПРОФИЛЬ OLX-продавца = ОДНО касание НАВСЕГДА, с любого аккаунта.
Даже если писать на другое его объявление, у продавца в чате видна история.

## Процедура перед работой с лидом

1. `git pull` этого репозитория.
2. Открыть `leads.json`. Проверить профиль продавца (поле `profile`) в `contacts` и в `claims`.
3. Если профиль там есть (в любом виде) — НЕ писать. Выбрать другого лида.
4. Если чисто: добавить в `claims` запись `{"profile":"XXXX","by":"<имя агента>","until":"<ISO дата+1 день>"}` и сделать `git add . && git commit -m "claim XXXX" && git push`.
5. Построить сайт, задеплоить, отправить сообщение.
6. После отправки: перенести из `claims` в `contacts` с полями repo/ad/date/account. `git push`.
7. Если claim чужой и просрочен (until в прошлом) — можно перехватить: обнови `by` и `until`, push.

Перед самой отправкой сообщения ещё раз `git pull` и проверь, что профиль не появился в contacts у другого агента.

## Правила контента (нарушение = брак)

- НИКАКИХ тире (— и –) в текстах сайтов и сообщениях. Замена: запятая, "і", "від ... до ...".
- НИКАКОГО бейджа/чипа/статуса на первом экране сайта (hero). Только заголовок + подзаголовок + кнопка.
- Никаких выдуманных фактов: отзывов, рейтингов, счётчиков, фейкового стажа.
- НИКОГДА не писать "мені в портфолію" / "щоб поповнити портфоліо".
- Сообщение по шаблону: приветствие + что увидел на OLX + "Я роблю сайти і зібрав для вас готовий" + ссылка + абзац "це не шахрайство, прикріплюю скріншот" + что внутри + "Віддам за символічну суму. Скажіть, цікаво?"
- К сообщению прикрепляется ПОЛНОСТРАНИЧНЫЙ скрин сайта (только сайт, без вкладок и адресной строки).
- Тексты для людей на украинском, живые, простые.

## Скрининг лида (до строительства сайта)

- В описании объявления нет ссылок (сайтов, facebook, instagram, telegram-ссылок).
- Не магазин, не бизнес-сторінка.
- Онлайн на OLX не позже ~3 недель назад.
- Профиль чистый: нет внешних ссылок в объявлениях.

## Техника

- Сайты: одна папка = один сайт, index.html (весь CSS/JS внутри) + img/ (hero.jpg, g1..g4.jpg, ~1600px, до 400КБ).
- Деплой: git repo на аккаунте zaryadkastandoff2-debug (токен у каждого агента свой от владельца),
  push main + POST /repos/.../pages {"source":{"branch":"main","path":"/"}}.
- Браузер: гостевой Chrome с CDP (--guest --remote-debugging-port=9222 --user-data-dir=<temp>).
  Второй аккаунт = второй инстанс на порту 9223. Скрипты принимают порт в env OLX_PORT.
- Скрипты (в папке scripts/ этого репо): olx-search.mjs (поиск карточек), olx-screen.mjs (скрининг объявления),
  check-profile.mjs (профиль), read-thread.mjs (читать чат), shot.mjs (полностраничный скрин),
  olx-send2.mjs (отправка сообщения с картинкой). Все работают через ЕДИНСТВЕННУЮ вкладку своего инстанса
  (гость блокирует создание вкладок через CDP).
- Фото для сайтов: images.pexels.com (прямой CDN, ?auto=compress&cs=tinysrgb&w=1600) или images.unsplash.com.
  ImageGen часто недоступен. Проверять байты FF D8.
